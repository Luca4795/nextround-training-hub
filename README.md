# NextRound Training Hub

## Project Description

NextRound Training Hub is a responsive web application designed for boxing athletes who want to manage workouts, explore exercises, update their athlete profile and send feedback.

The project was built using HTML, CSS and JavaScript. It includes dynamic DOM manipulation, form validation, localStorage, fake authentication, Fetch API, images and HTML5 video elements.

## Features

- Fake login system using localStorage
- Dynamic dashboard with login/logout state
- Daily training quote loaded from an external API using Fetch API
- Workout creation form with validation
- Workout list rendered dynamically with JavaScript
- Workout filtering by category
- Workout deletion with localStorage update
- Exercise library with category filter
- Video demonstration for each exercise
- Show/hide exercise details
- Athlete profile form with saved data
- Feedback form with validation
- Responsive design with media queries
- Images and videos stored inside the assets folder

## Pages

- `login.html` - fake login page
- `index.html` - dashboard
- `workouts.html` - workout management
- `exercises.html` - exercise library with videos
- `profile.html` - athlete profile
- `feedback.html` - feedback form

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- localStorage
- Fetch API
- HTML5 Video
- Responsive Design

## How to Use

1. Open `login.html`.
2. Enter an email and password.
3. Go to the dashboard.
4. Load a daily quote using the Fetch API button.
5. Create, filter and delete workouts.
6. Explore exercises and watch demonstration videos.
7. Update the athlete profile.
8. Send feedback through the feedback form.
